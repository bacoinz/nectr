FeedbackComentários

Comments at the exact second.Comentários no segundo certo.

  • A second or a range, typed or as a voice note recorded in the browser. They appear as markers on the waveform.Um segundo ou um intervalo, por escrito ou com uma nota de voz gravada no browser. Aparecem como marcas na forma de onda.
  • Requests are marked open or done, along with the version that fixed them. One page lists everything still open.Pedidos marcados como abertos ou feitos, com a versão que os resolveu. Uma página junta tudo o que está por fazer.

DeployPublica

npm run deploy, then protect your pages with Access (a one-time PIN by email).npm run deploy, e depois protege as tuas páginas com o Access (um código por email).

Prefer a Raspberry Pi or a NAS? A ready-made prompt swaps D1, R2 and Access for SQLite, a folder on disk and your own login.Preferes um Raspberry Pi ou um NAS? Um prompt pronto troca o D1, o R2 e o Access por SQLite, uma pasta no disco e um login teu.

# try it on your computer
$ git clone https://github.com/bacoinz/nectr
$ cd nectr && npm install
$ cp .dev.vars.example .dev.vars
$ npm run db:migrate:local
$ npm run dev

# → http://localhost:5173

# online: follow docs/setup.md, then
$ npm run db:migrate:remote
$ npm run deploy
